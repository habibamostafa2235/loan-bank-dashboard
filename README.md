# 📊 Loan Bank Dashboard (Excel)

## 📌 Project Overview

This project is an interactive Excel dashboard designed to analyze loan data and provide meaningful insights into loan approvals, repayment behavior, borrower risk, and overall financial performance. The dashboard helps transform raw data into actionable business insights for better decision-making.

---

## 🎯 Objectives

- Analyze loan approval and rejection trends.
- Identify high-risk borrower categories.
- Monitor repayment behavior.
- Track default rates.
- Build an interactive dashboard for business reporting.

---

## 📂 Dataset

- Loan customer data
- Loan transactions
- Borrower information
- Repayment records

---

## 💡 Business Insights
